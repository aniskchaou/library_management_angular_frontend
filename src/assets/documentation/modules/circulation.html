Circulation Module Documentation

Module Description

The Circulation module manages the borrowing and returning process of library items by members. It includes fields for entering member and book details, issue and return dates, penalties, and return status.

Fields and Descriptions

Member Name *:

  • Description: The name of the member borrowing the item.
  • Usage: Enter the member's full name.
  • Example: "John Doe"
  • Validation: Must be a valid string, required field.

Book Name *:

  • Description: The title of the book being borrowed.
  • Usage: Enter the name of the book.
  • Example: "To Kill a Mockingbird"
  • Validation: Must be a valid string, required field.

Writer *:

  • Description: The author of the book being borrowed.
  • Usage: Enter the author's name.
  • Example: "Harper Lee"
  • Validation: Must be a valid string, required field.

Issue Date *:

  • Description: The date when the book is issued to the member.
  • Usage: Enter the issue date in the format dd/mm/yyyy.
  • Example: "01/08/2024"
  • Validation: Must be a valid date format (dd/mm/yyyy), required field.

Last Date *:

  • Description: The last date by which the book is expected to be returned.
  • Usage: Enter the last date in the format dd/mm/yyyy.
  • Example: "15/08/2024"
  • Validation: Must be a valid date format (dd/mm/yyyy), required field.

To Return *:

  • Description: The date by which the book is to be returned, same as the last date.
  • Usage: Enter the return date in the format dd/mm/yyyy.
  • Example: "15/08/2024"
