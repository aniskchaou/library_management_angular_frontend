The Member module is designed to manage information about the library's members. It includes fields for personal information, membership details, contact information, and settings related to borrowing and accessing library services.

Fields and Descriptions

Image:

  • Description: A field to upload or link to a profile image for the member.
  • Usage: Upload an image file representing the member.
  • Example: "Profile picture"
  • Validation: Must be a valid image file format.

Allow Member Login?

  • Description: Indicates whether the member is allowed to log in to the library system.
  • Usage: Select "Yes" to allow login, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Booking Quota:

  • Description: The quota of bookings that the member is allowed to make.
  • Usage: Enter the booking quota value.
  • Example: "5"
  • Validation: Must be a positive integer.

Type:

  • Description: The type of membership the member holds.
  • Usage: Enter the membership type.
  • Example: "Regular", "Student"
  • Validation: Must be a non-empty string.

Card number*:

  • Description: The unique card number assigned to the member.
  • Usage: Enter the member's card number.
  • Example: "1234567890"
  • Validation: Must be a non-empty string and unique.

Library*:

  • Description: The library branch the member is associated with.
  • Usage: Select the library branch from the list.
  • Example: "Centerville"
  • Validation: Must be a non-empty string and match an existing library branch.

Required Category*:

  • Description: The membership category the member falls under.
  • Usage: Select the category from the list.
  • Example: "STUDENT"
  • Validation: Must be a non-empty string and match an existing category.

Sort 1:

  • Description: A sorting field for organizational purposes.
  • Usage: Enter a value for sorting.
  • Example: "Last Name"
  • Validation: Must be a non-empty string.

Sort 2:

  • Description: An additional sorting field for organizational purposes.
  • Usage: Enter a value for sorting.
  • Example: "First Name"
  • Validation: Must be a non-empty string.

Allow auto-renewal of items:

  • Description: Indicates whether the member is allowed to have items auto-renewed.
  • Usage: Select "Yes" to allow auto-renewal, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Registration date:

  • Description: The date the member registered.
  • Usage: Enter the registration date in the format dd/mm/yyyy.
  • Example: "06/04/2024"
  • Validation: Must be a valid date format (dd/mm/yyyy).

Expiry date (leave blank for auto calc):

  • Description: The expiry date of the membership. Leave blank if the system calculates it automatically.
  • Usage: Enter the expiry date in the format dd/mm/yyyy or leave blank.
  • Example: "06/04/2026"
  • Validation: Must be a valid date format (dd/mm/yyyy) if entered.

OPAC note:

  • Description: A note that appears on the member's user page in the OPAC.
  • Usage: Enter the OPAC note.
  • Example: "This message appears on this patron's user page in the OPAC."
  • Validation: Must be a non-empty string.

Circulation note:

  • Description: A note that displays when checking out items to this member.
  • Usage: Enter the circulation note.
  • Example: "This message displays when checking out to this patron."
  • Validation: Must be a non-empty string.

Username:

  • Description: The member's username for logging in to the system.
  • Usage: Enter the username.
  • Example: "aniket.pandit1"
  • Validation: Must be a non-empty string and unique.

Password:

  • Description: The member's password for logging in to the system.
  • Usage: Enter the password.
  • Example: "••••"
  • Validation: Must meet the minimum password length requirement.

Minimum password length:

  • Description: The minimum length required for the member's password.
  • Usage: Enter the minimum password length.
  • Example: "3"
  • Validation: Must be a positive integer.

Confirm password:

  • Description: Field to confirm the member's password.
  • Usage: Enter the password again to confirm.
  • Example: "••••"
  • Validation: Must match the password entered in the Password field.

Lost card:

  • Description: Indicates whether the member has reported a lost card.
  • Usage: Select "Yes" if the card is lost, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Gone no address:

  • Description: Indicates whether the member has no address on record.
  • Usage: Select "Yes" if the member has no address, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Patron restrictions:

  • Description: Displays any restrictions currently placed on the member.
  • Usage: This is an informational field.
  • Example: "Patron is currently unrestricted."
  • Validation: N/A

Add manual restriction:

  • Description: Allows adding a manual restriction to the member's account.
  • Usage: Click to add a restriction.
  • Example: "Click here to add a restriction."
  • Validation: N/A

Salutation:

  • Description: The member's salutation (e.g., Mr., Ms., Dr.).
  • Usage: Enter the salutation.
  • Example: "Mr.", "Ms."
  • Validation: Must be a valid string.

Surname:

  • Description: The member's last name.
  • Usage: Enter the surname.
  • Example: "Smith", "Doe"
  • Validation: Must be a non-empty string.

First name:

  • Description: The member's first name.
  • Usage: Enter the first name.
  • Example: "John", "Jane"
  • Validation: Must be a non-empty string.

Date of birth:

  • Description: The member's date of birth.
  • Usage: Enter the date of birth in the format dd/mm/yyyy.
  • Example: "01/01/2000"
  • Validation: Must be a valid date format (dd/mm/yyyy).

Age:

  • Description: The member's age calculated from the date of birth.
  • Usage: This is an informational field.
  • Example: "21 years 4 months"
  • Validation: N/A

Gender:

  • Description: The member's gender.
  • Usage: Enter or select the gender.
  • Example: "Male", "Female", "Other"
  • Validation: Must be a valid string.

Street number:

  • Description: The member's street number.
  • Usage: Enter the street number.
  • Example: "123"
  • Validation: Must be a non-empty string.

Address:

  • Description: The member's address.
  • Usage: Enter the full address.
  • Example: "123 Main St, Apt 4B"
  • Validation: Must be a non-empty string.

City:

  • Description: The city where the member resides.
  • Usage: Enter the city name.
  • Example: "New York"
  • Validation: Must be a non-empty string.

State:

  • Description: The state where the member resides.
  • Usage: Enter the state name.
  • Example: "NY"
  • Validation: Must be a non-empty string.

ZIP/Postal code:

  • Description: The ZIP or postal code for the member's address.
  • Usage: Enter the ZIP or postal code.
  • Example: "10001"
  • Validation: Must be a valid postal code.

Country:

  • Description: The country where the member resides.
  • Usage: Enter the country name.
  • Example: "United States"
  • Validation: Must be a non-empty string.

Primary phone:

  • Description: The primary phone number for the member.
  • Usage: Enter the primary phone number.
  • Example: "(123) 456-7890"
  • Validation: Must be a valid phone number format.

Secondary phone:

  • Description: An additional phone number for the member.
  • Usage: Enter the secondary phone number.
  • Example: "(098) 765-4321"
  • Validation: Must be a valid phone number format.

Primary email:

  • Description: The primary email address for the member.
  • Usage: Enter the primary email address.
  • Example: "john.doe@example.com"
  • Validation: Must be a valid email address format.

Secondary email:

  • Description: An additional email address for the member.
  • Usage: Enter the secondary email address.
  • Example: "jane.doe@example.com"
  • Validation: Must be a valid email address format.

Fax:

  • Description: The fax number for the member.
  • Usage: Enter the fax number.
  • Example: "(123) 456-7899"
  • Validation: Must be a valid fax number format.

Main contact method:

  • Description: The preferred method of contact for the member.
  • Usage: Enter the main contact method (e.g., phone, email).
  • Example: "Email"
  • Validation: Must be a valid string.
