Renew Module Documentation

Module Description

The Renew module allows library staff to extend the borrowing period of checked-out items. It includes fields for scanning the item barcode, setting a new due date, and an option to forgive fines on return.

Fields and Descriptions

Item Barcode:

  • Description: The barcode of the item being renewed.
  • Usage: Scan or enter the barcode of the item.
  • Example: "Barcode 1"
  • Validation: Must be a valid barcode string.

Renewal Due Date:

  • Description: The new due date for the item after renewal.
  • Usage: Enter the new due date in the format dd/mm/yyyy.
  • Example: "30/07/2024"
  • Validation: Must be a valid date format (dd/mm/yyyy).

Forgive fines on return:

  • Description: An option to forgive any fines that may have accrued if the item is returned late.
  • Usage: Select "Yes" to forgive fines upon return, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).
