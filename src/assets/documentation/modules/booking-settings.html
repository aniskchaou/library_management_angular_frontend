The Booking Setting module allows library administrators to configure the booking and circulation settings for members. It includes fields for setting default durations, quotas, and enabling member self-service options for checkouts and check-ins.

Fields and Descriptions

Booking Time:

  • Description: Sets the default circulation duration in days, changing the default "Return Date" in the circulation form.
  • Usage: Enter the number of days for the default circulation duration.
  • Example: "14"
  • Validation: Must be a positive integer.

Booking Quota:

  • Description: The combined maximum number of items a member can request, checkout, or loan at a time.
  • Usage: Enter the booking quota value.
  • Example: "5"
  • Validation: Must be a positive integer.

Enable member checkouts:

  • Description: Enables or disables the ability for members to do self-checkout of library items through their member area. Suitable for corporate, small business, office, family, and other unattended libraries.
  • Usage: Select "Yes" to enable self-checkouts, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Enable member check-ins:

  • Description: Enables or disables the ability for members to return items by themselves.
  • Usage: Select "Yes" to enable self-check-ins, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Enable member check-ins for overdue items:

  • Description: Enables or disables the ability for members to return overdue items by themselves. This setting only works when "Enable member check-ins" is enabled.
  • Usage: Select "Yes" to enable self-check-ins for overdue items, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Member:

  • Description: Specifies which member types can do self-checkouts and check-ins.
  • Usage: Select the applicable member types from the list.
  • Example: "All Members"
  • Validation: Must be a valid member type.

Checkout Time:

  • Description: Sets the default checkout duration in days. This will be displayed in the request form.
  • Usage: Enter the default checkout duration in days.
  • Example: "7"
  • Validation: Must be a positive integer.

Checkout Limit:

  • Description: The maximum checkout duration in days. Members cannot exceed this limit for self-checkout.
  • Usage: Enter the maximum checkout duration in days.
  • Example: "21"
  • Validation: Must be a positive integer.

Checkout Quota:

  • Description: The maximum number of items a member can check out at a time.
  • Usage: Enter the checkout quota value.
  • Example: "10"
  • Validation: Must be a positive integer.
