User Settings Module Documentation

Module Description

The User Settings module is used to configure the parameters related to user registration and roles within the library management system. It includes options for allowing user registration, requiring email verification, and setting a default user role. These settings help manage user access and ensure secure and organized user management.

Fields and Descriptions

Allow User Registration:

  • Description: Determines whether new users are permitted to register themselves in the library management system.
  • Usage: Select "Yes" to allow users to register on their own, or "No" to disable self-registration and require administrative approval for new accounts.
  • Example: "Yes"
  • Validation: Must be a boolean value (Yes/No).

Require Email Verification for New Users:

  • Description: Specifies whether new users must verify their email addresses before their accounts are activated.
  • Usage: Select "Yes" to require email verification, which adds an extra layer of security by ensuring the validity of the user’s email address. Select "No" to bypass email verification.
  • Example: "Yes"
  • Validation: Must be a boolean value (Yes/No).

Default User Role:

  • Description: Defines the default role assigned to users upon registration or account creation.
  • Usage: Select the role that new users will automatically receive. This role typically defines the permissions and access levels available to the user.
  • Example: "Member", "Guest"
  • Validation: Must be a valid role name that exists within the system’s role management configuration.
