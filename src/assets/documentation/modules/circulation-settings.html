Circulation Settings Module Documentation

Module Description

The Circulation Settings module allows administrators to configure the parameters for managing the circulation of library materials. This includes settings related to item types, loan periods, renewals, and holds. Proper configuration of these settings ensures smooth operation and management of library resources.

Fields and Descriptions

Item Type:

  • Description: Specifies the type of item to which the settings apply, such as books, DVDs, or journals.
  • Usage: Select or enter the type of item for which you want to configure the circulation settings.
  • Example: "Book", "DVD", "Magazine"
  • Validation: Must correspond to a valid item type defined in the system.

Loan Period (days):

  • Description: Defines the standard loan duration for the selected item type, specified in days.
  • Usage: Enter the number of days items of the specified type can be borrowed before they are due back.
  • Example: "14" (for a 2-week loan period)
  • Validation: Must be a positive integer representing the number of days.

Renewals Allowed:

  • Description: Indicates whether items of the specified type can be renewed, and if so, how many times.
  • Usage: Choose "Yes" to allow renewals or specify the number of renewals allowed. Select "No" to disallow renewals.
  • Example: "Yes, 3 times" or "No"
  • Validation: Must be a boolean value (Yes/No) or specify the number of renewals allowed.

Holds Allowed:

  • Description: Determines whether items of the specified type can be placed on hold by users.
  • Usage: Select "Yes" to allow holds or "No" to disallow users from placing holds on these items.
  • Example: "Yes"
  • Validation: Must be a boolean value (Yes/No).
