Checkin Module Documentation

Module Description

The Checkin module allows library staff to process the return of borrowed items. It includes fields for scanning the item barcode, entering the return due date, and an option to remember the return date for subsequent check-ins.

Fields and Descriptions

Item Barcode:

  • Description: The barcode of the item being checked in.
  • Usage: Scan or enter the barcode of the item.
  • Example: "Barcode 1"
  • Validation: Must be a valid barcode string.

Return Due Date:

  • Description: The date by which the item was due to be returned.
  • Usage: Enter the due date in the format dd/mm/yyyy.
  • Example: "30/07/2024"
  • Validation: Must be a valid date format (dd/mm/yyyy).

Remember return date for next check in:

  • Description: An option to remember the return date for the next check-in, making the process more efficient.
  • Usage: Select "Yes" to remember the return date for the next check-in, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).
