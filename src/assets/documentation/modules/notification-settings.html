Notification Settings Module Documentation

Module Description

The Notification Settings module allows users to configure their preferences for receiving alerts related to library items and activities. This includes notifications for item availability, due dates, and new arrivals. Proper configuration ensures that users stay informed about important updates and changes related to their library interactions.

Fields and Descriptions

Receive Alerts for Item Availability:

  • Description: Determines whether users will receive notifications when an item they are interested in becomes available.
  • Usage: Select "Yes" to enable alerts for item availability, or "No" to disable these notifications.
  • Example: "Yes"
  • Validation: Must be a boolean value (Yes/No).

Receive Alerts for Due Dates:

  • Description: Specifies whether users will receive notifications about upcoming due dates for borrowed items.
  • Usage: Choose "Yes" to enable due date alerts, which will remind users of impending deadlines to return or renew items. Select "No" to disable these notifications.
  • Example: "Yes"
  • Validation: Must be a boolean value (Yes/No).

Receive Alerts for New Arrivals:

  • Description: Indicates whether users will receive notifications when new items are added to the library's collection.
  • Usage: Select "Yes" to receive alerts about new arrivals, keeping users informed about the latest additions to the library. Choose "No" to disable these notifications.
  • Example: "No"
  • Validation: Must be a boolean value (Yes/No).
