Type Member Module Documentation

Module Description

The Type Member module is designed to manage different membership types within the library system. It allows librarians to define various membership categories, including their descriptions, enrollment periods, fees, and other relevant information.

Fields and Descriptions

Type Member*:

  • Description: The name or title of the membership type.
  • Usage: Enter the name of the membership type.
  • Example: "Regular", "Student", "Senior Citizen"
  • Validation: Must be a non-empty string and unique.

Category code:

  • Description: A unique code to identify the membership category.
  • Usage: Enter a unique code for the membership category.
  • Example: "REG", "STU", "SEN"
  • Validation: Must be a non-empty string and unique.

Description:

  • Description: A detailed description of the membership type.
  • Usage: Enter a comprehensive description of the membership type.
  • Example: "Membership for regular adult patrons", "Membership for students with valid ID"
  • Validation: Must be a non-empty string.

Enrollment period:

  • Description: The duration of the membership in months.
  • Usage: Enter the enrollment period in months.
  • Example: "12", "24"
  • Validation: Must be a positive integer.

Upper age limit:

  • Description: The maximum age limit for this membership type, if applicable.
  • Usage: Enter the upper age limit.
  • Example: "65", "30"
  • Validation: Must be a positive integer or leave blank if not applicable.

Enrollment fee:

  • Description: The fee charged for enrolling in this membership type.
  • Usage: Enter the enrollment fee amount.
  • Example: "50.00", "0.00"
  • Validation: Must be a valid monetary value.

Hold fee:

  • Description: The fee charged for placing holds on items for this membership type.
  • Usage: Enter the hold fee amount.
  • Example: "0.00", "1.00"
  • Validation: Must be a valid monetary value.

Category type:

  • Description: The general category of the membership type (e.g., Adult, Student).
  • Usage: Enter the category type.
  • Example: "Adult", "Student"
  • Validation: Must be a non-empty string.

Minimum password length:

  • Description: The minimum length required for passwords for this membership type.
  • Usage: Enter the minimum password length.
  • Example: "8", "12"
  • Validation: Must be a positive integer.

Require strong password:

  • Description: Indicates whether a strong password is required (e.g., a combination of letters, numbers, and special characters).
  • Usage: Select "Yes" if a strong password is required, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Block expired patrons:

  • Description: Indicates whether patrons with expired memberships are blocked from borrowing or accessing services.
  • Usage: Select "Yes" if expired patrons should be blocked, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).
