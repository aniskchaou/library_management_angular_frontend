Author Module Documentation

Module Description

The Author module is designed to manage information about authors whose works are part of the library's collection. It allows librarians to store and organize detailed information about each author, including their biography, publications, awards, and references.

Fields and Descriptions

Writer Name*:

  • Description: The full name of the author.
  • Usage: Enter the author's full name.
  • Example: "J.K. Rowling", "George Orwell"
  • Validation: Must be a non-empty string and unique.

Note*:

  • Description: Additional notes or information about the author.
  • Usage: Enter any relevant notes about the author.
  • Example: "Known for the Harry Potter series", "Used the pen name Eric Arthur Blair"
  • Validation: Must be a non-empty string.

Date of Birth:

  • Description: The birthdate of the author.
  • Usage: Enter the author's date of birth in the format jj/mm/aaaa.
  • Example: "31/07/1965"
  • Validation: Must be a valid date format (jj/mm/aaaa).

Died:

  • Description: Indicates whether the author is deceased.
  • Usage: Select "Yes" if the author is deceased, otherwise select "No".
  • Example: "Yes", "No"
  • Validation: Must be a boolean value (Yes or No).

Date of Death:

  • Description: The date of death of the author (if applicable).
  • Usage: Enter the author's date of death in the format jj/mm/aaaa.
  • Example: "21/01/1950"
  • Validation: Must be a valid date format (jj/mm/aaaa) and only applicable if the "Died" field is set to "Yes".

Bio:

  • Description: A brief biography of the author.
  • Usage: Enter a concise biography of the author.
  • Example: "J.K. Rowling is a British author, best known for writing the Harry Potter series."
  • Validation: Must be a non-empty string.

Publications:

  • Description: A list of notable works published by the author.
  • Usage: Enter a comma-separated list of the author's publications.
  • Example: "Harry Potter and the Philosopher's Stone, 1984, Animal Farm"
  • Validation: Must be a non-empty string.

Awards:

  • Description: A list of awards and honors received by the author.
  • Usage: Enter a comma-separated list of awards and honors.
  • Example: "Hugo Award, Nebula Award, Pulitzer Prize"
  • Validation: Must be a non-empty string.

References:

  • Description: References or citations relevant to the author's work or biography.
  • Usage: Enter any relevant references or citations.
  • Example: "Biography source: Encyclopedia Britannica, Literary analysis: The New York Times"
  • Validation: Must be a non-empty string.
