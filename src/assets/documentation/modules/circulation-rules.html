Circulation Setting Module Documentation

Module Description

The Circulation Setting module allows library administrators to configure various settings related to fines, loan periods, and item handling. It includes fields for setting fine amounts, loan durations, and policies on renewals and holds.

Fields and Descriptions

Fine per Day:

  • Description: The amount of fine charged per day for overdue items.
  • Usage: Enter the fine amount in the applicable currency.
  • Example: "1.00" (for $1.00 per day)
  • Validation: Must be a positive monetary value.

Max Fine:

  • Description: The maximum fine that can be accrued for overdue items.
  • Usage: Enter the maximum fine amount in the applicable currency.
  • Example: "10.00" (for a maximum of $10.00)
  • Validation: Must be a positive monetary value.

Item Type:

  • Description: The type of items that these circulation settings apply to.
  • Usage: Select or enter the item type (e.g., books, DVDs).
  • Example: "Books"
  • Validation: Must be a valid item type from the predefined list.

Loan Period:

  • Description: The standard duration for which an item can be borrowed.
  • Usage: Enter the loan period in days.
  • Example: "14" (for a 14-day loan period)
  • Validation: Must be a positive integer.

Renewals Allowed:

  • Description: The number of times an item can be renewed.
  • Usage: Enter the maximum number of renewals allowed.
  • Example: "3" (for up to 3 renewals)
  • Validation: Must be a non-negative integer.

Holds Allowed:

  • Description: The number of holds that can be placed on an item.
  • Usage: Enter the maximum number of holds allowed.
  • Example: "5" (for up to 5 holds)
  • Validation: Must be a non-negative integer.
