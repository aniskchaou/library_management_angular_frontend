Basket Module Documentation

Module Description

The Basket module allows users to manage and track items within a basket, which may be used for ordering or organizing items. It includes fields for naming the basket, specifying billing and delivery places, and adding notes. The module also includes an option for creating items based on specific criteria.

Fields and Descriptions

Basket Name:

  • Description: The name assigned to the basket for identification purposes.
  • Usage: Enter a descriptive name for the basket.
  • Example: "New Arrivals Basket"
  • Validation: Must be a valid string.

Billing Place:

  • Description: The location where billing for items in the basket will be processed.
  • Usage: Enter the billing address or place.
  • Example: "Central Library Billing Office"
  • Validation: Must be a valid string.

Delivery Place:

  • Description: The location where the items in the basket will be delivered.
  • Usage: Enter the delivery address or place.
  • Example: "Centerville Branch, Room 204"
  • Validation: Must be a valid string.

Vendor:

  • Description: The vendor responsible for supplying the items in the basket.
  • Usage: Select or enter the name of the vendor.
  • Example: "Books & More Ltd."
  • Validation: Must be a valid vendor from the predefined list or database.

Internal Note:

  • Description: Any internal notes or comments related to the basket that are not visible to external parties.
  • Usage: Enter any relevant internal notes.
  • Example: "For review before final order confirmation."
  • Validation: Must be a valid string.

Vendor Note:

  • Description: Notes or instructions to be communicated to the vendor.
  • Usage: Enter any specific instructions or comments for the vendor.
  • Example: "Please include tracking information with shipment."
  • Validation: Must be a valid string.

Create Items When:

  • Description: Specifies when items should be created based on the basket's contents.
  • Usage: Select or enter the condition under which items will be created.
  • Example: "When Basket is Confirmed" or "Immediately"
  • Validation: Must be a valid condition or event trigger.
