Barcode Generation Module Documentation

Module Description

The Barcode Generation module is used to create barcodes for library items. It allows you to specify various parameters such as the ISBN, barcode type, dimensions, and display options to generate and customize barcodes according to your needs.

Fields and Descriptions

ISBN:

  • Description: The International Standard Book Number (ISBN) that will be encoded in the barcode.
  • Usage: Enter the ISBN number of the book or item for which the barcode is being generated.
  • Example: "9783161484100"
  • Validation: Must be a valid ISBN number.

Type:

  • Description: The type of barcode symbology to be used.
  • Usage: Select the barcode type based on your requirements (e.g., Code 128).
  • Example: "Code 128"
  • Validation: Must be a valid barcode type from available options.

Width:

  • Description: The width of the barcode in pixels.
  • Usage: Enter the desired width for the barcode.
  • Example: "200"
  • Validation: Must be a positive integer.

Height:

  • Description: The height of the barcode in pixels.
  • Usage: Enter the desired height for the barcode.
  • Example: "100"
  • Validation: Must be a positive integer.

Display Value:

  • Description: Whether or not to display the encoded value below the barcode.
  • Usage: Select "Yes" to display the value or "No" to hide it.
  • Example: "Yes"
  • Validation: Must be a boolean value (Yes or No).

Font:

  • Description: The font to be used for displaying the barcode value (if Display Value is set to Yes).
  • Usage: Enter the name of the font to be used.
  • Example: "Arial"
  • Validation: Must be a valid font name available in the system.

Color:

  • Description: The color of the barcode and the text (if Display Value is set to Yes).
  • Usage: Enter the color code or name for the barcode.
  • Example: "Black"
  • Validation: Must be a valid color name or hexadecimal color code.

Margin:

  • Description: The margin size around the barcode in pixels.
  • Usage: Enter the margin size to ensure adequate spacing around the barcode.
  • Example: "10"
  • Validation: Must be a positive integer.

Rotation:

  • Description: The rotation angle of the barcode.
  • Usage: Enter the rotation angle in degrees (e.g., 0, 90, 180, 270).
  • Example: "0"
  • Validation: Must be a valid degree value (0, 90, 180, 270).
