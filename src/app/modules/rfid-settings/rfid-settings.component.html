info Setup Instructions

  1. Install the Library Lab RFID Bridge middleware on the circulation desk PC.
  2. Connect your RFID reader hardware (USB or network).
  3. Configure the bridge to point to {{ 'POST /rfid/scan' }}.
  4. Register tags using the form above (or bulk-import via CSV).
  5. The barcode scanner works out-of-the-box — just scan in any text input.
